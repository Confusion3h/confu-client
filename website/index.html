Features

The same client the launcher starts. FPS mode is already on. Worlds, capes and music stay in your own folder.

FPS boost preset

On the first launch, with FPS mode already on: fast graphics, short render distance, VBOs, fewer particles, no entity shadows, vsync off. Four extra JVM flags sit on top of the existing G1 set. On the same superflat, 12 samples, llvmpipe software GL: 78 fps average before (71–85), 81 after (79–85). That is the safe ceiling. Chunk delay, bot removal and entity culling stay off, so real players stay on screen. A GPU will sit higher than this software-GL pass.

Microsoft login

Sign in with Microsoft from the launcher. It uses the built-in Live desktop client. There is no Azure app to register and no extra token file to paste.

Music player

Play a folder of WAV, MP3 or OGG, or paste a YouTube or SoundCloud link. yt-dlp and FFmpeg download themselves and are checked against a pinned SHA-256 before they run.

Custom capes

Cosmetics, then Custom. Add a PNG and press F5 to see it. Capes stay on this machine.

ESC menu

Escape in a world opens the vanilla Options screen, including Open Confu Client menu. Right Shift opens that menu from anywhere, including the title screen.

Singleplayer

The 1.8.9 singleplayer list, worlds and all. The main menu is Singleplayer, Multiplayer and Settings. Disconnect returns you there without dropping the process.

Java 8, Minecraft 1.8.9

Every archive ships a JRE. Windows x64, Linux and macOS Intel use Temurin 8. macOS Apple Silicon uses Azul Zulu 8. Windows ARM64 uses a native Microsoft Build of OpenJDK 17, with a small compatibility jar so 1.8.9 still starts. You do not install Java yourself.

FAQ

Windows says the installer is an unrecognized app

SmartScreen shows “Windows protected your PC” because this build is unsigned. There is no Authenticode certificate on the file, so Windows cannot name a publisher it already trusts. The installer still carries a version resource (product and company name Confu Client), a DPI-aware manifest, and LZMA compression. It is not packed with UPX. On the warning, choose More info, then Run anyway.

macOS says Confu Client is damaged

macOS marks a downloaded app with a quarantine flag. This build is ad-hoc signed, not notarised, so the first open can say the app is damaged. Right-click Confu Client.app and choose Open. Or, in Terminal, run xattr -dr com.apple.quarantine "/path/Confu Client.app".

Which file is mine?

The Download button matches Windows, macOS or Linux, and x64 or ARM64, from the browser. Windows ARM64 is the native Java 17 build. The Windows x64 installer also runs on ARM Windows, under emulation, and says so when it starts. Linux and macOS archives unpack and run confu or the app bundle. They are not .exe installers.

Do I install Java first?

No. Each archive includes a JRE. The game is Minecraft 1.8.9. First launch downloads the game assets into the Confu folder (%APPDATA%\.confu on Windows, ~/.confu on Linux and macOS).

Where is the FPS number from?

One superflat world, 12 samples, before and after the four JVM flags, on llvmpipe (Mesa software OpenGL), not a discrete GPU. Average 78 before, 81 after. The preset was already at the safe graphics ceiling, so the gain is small and honest.
